# Linux v0.22.0 Catch-up Plan

## Scope

- Upstream range: `v0.19.0..v0.22.0`.
- Release target: exact upstream tag `v0.22.0` (`8192f0ba48ebd3d716f77c8a02c8bec06535e708`).
- Excluded: the five commits after `v0.22.0` on `upstream/master`.
- Linux base: `origin/linux-port` at `e1067db3f8476e5e2c3d550daead3732863c1844`.
- Integration rule: inherit host-free `agtermCore` behavior unchanged, keep GTK/libadwaita and Glibc
  adaptations in Linux-owned paths, and preserve the GLib `MainTimer` seam.
- Protected file: `agtermCore/Tests/agtermCoreTests/ConfigPathsTests.swift` remains upstream-identical.
- Excluded worktree artifacts: `agterm-linux/` build output, `dist-linux/`, legacy checksum files, and
  `site/_screenshot.png` are never staged unless explicitly selected.

## Parity inventory

### Shared behavior inherited from upstream

- [x] Current-workspace targeting and close reselection within flagged/focused visible sets.
- [x] Lossy decoding for optional persisted fields and control-character sanitization.
- [x] Picker label-only matching, caller ordering, prefilled query, and itemless custom prompts.
- [x] Dashboard pane-reference grammar, deduplication, limits, read-back, and promotion model.
- [x] Pane-scoped overlay model, protocol, CLI arguments, state, and read-back.
- [x] HUD model, dispatcher, protocol, CLI, layout, position, color, helper contract, and read-back.
- [x] `hasSplit` tree read-back and hidden-split CLI presentation.
- [x] Palette search scoring, configurable interface metrics, first-run decision, accessibility insert
  policy, command-path resolution, and revised starter keymap catalog.
- [x] Shared restore, scratch/split, foreground-process, snapshot, notification, and settings fixes.

### Linux adapter and user-visible work

- [ ] Make the Linux package compile against the v0.22.0 shared protocol and action surfaces.
- [ ] Implement pane-scoped overlay open/close/result behavior for GTK, including per-pane ownership,
  teardown, focus, read-back, and incompatible-argument validation inherited from the dispatcher.
- [ ] Implement passive session HUD open/update/close on GTK without stealing focus; keep helper body
  files atomic and clean them on every permanent teardown.
- [ ] Accept dashboard `:left`/`:right` members in GTK, preserve exact-pane focus on entry, and follow a
  promoted split survivor without reparenting `GtkGLArea` surfaces.
- [ ] Add native workspace-row click expansion, Copy Name context actions, and split-divider double-click
  reset while preserving multi-selection and drag/drop behavior.
- [ ] Add the interface font-size setting to the GTK palette, picker, switcher, and recent rows, centered
  and clamped over the terminal region.
- [ ] Add native first-run guidance for Linux integrations, using the existing status-driven Preferences
  install paths and never changing files without the existing preview/confirmation flow.
- [ ] Audit GTK/AT-SPI terminal text insertion against `AccessibilityInsert`; expose a native equivalent
  where GTK permits it, otherwise document the exact toolkit limitation.
- [ ] Apply the upstream scratch-first split toggle, session realization polling, overlay/quick muting,
  close/restore ordering, dark-launch environment, cursor, and focus fixes to GTK equivalents.
- [ ] Carry command-launch PATH resolution and the revised starter keymap without macOS-only assumptions.
- [ ] Preserve native Linux notification policy: no fabricated sound field, Dock bounce, TCC, or AppKit
  permission behavior.

### Control, CLI, and documentation surfaces

- [ ] Route all 74 public commands through the Linux dispatcher or document a platform exemption.
- [ ] Keep Linux-local `agtermctl` arguments, human output, JSON round trips, request-size behavior, and
  read-back synchronized with upstream `agtermctlKit`.
- [ ] Add focused Linux control tests for pane overlays, HUDs, dashboard pane refs, `hasSplit`, and every
  newly mutable/readable field.
- [ ] Update `plugins/agterm/skills/agterm/`, README, Linux docs, and site mirrors only for behavior that
  has been implemented and verified on Linux.
- [ ] Update README's Linux parity version from v0.19.0 to v0.22.0 after every required item passes.

### Platform exemptions

- [x] macOS TCC entitlements, usage strings, signing, notarization, and entitlement-free helper checks.
- [x] AppKit's duplicate fullscreen item, Settings-window Cmd-W routing, traffic-light/full-bleed titlebar,
  Dock menu/bounce, Finder naming, and Reduce Motion/Transparency implementation details.
- [x] MacWhisper-specific AX probing; Linux parity is evaluated through GTK accessibility and AT-SPI.
- [x] macOS-only cookbook/runtime shell assumptions and macOS release/Homebrew mechanics.

## Validation commands

Run with versions derived from `.github/workflows/ci.yml` and `.github/workflows/release-linux.yml`.

```sh
mise install swift@6.3.2 swiftlint@0.65.0
mise x swift@6.3.2 -- swift --version
mise x swiftlint@0.65.0 -- swiftlint version
cd agtermCore && mise x swift@6.3.2 -- swift test
cd .. && mise x swiftlint@0.65.0 -- swiftlint lint --strict --quiet
scripts/setup-linux.sh
cd agterm-linux && mise x swift@6.3.2 -- swift test
mise x swift@6.3.2 -- swift build --product agtermctl-linux
mise x swift@6.3.2 -- swift build --product AgtermLinux
mise x swift@6.3.2 -- swift build -c release
cd .. && scripts/test-linux-ui.sh
scripts/check-linux-core-boundary.sh v0.22.0
scripts/check-linux-cli-drift.sh
git diff --check
```

Before release, also run `make packages-linux VERSION=0.22.0` and
`scripts/verify-linux-packages.sh 0.22.0` when the pinned packaging tools are available.

Move this file to `docs/plans/completed/` only after the required parity work, documentation, tests,
builds, runtime checks, branch CI, and package verification all pass.
