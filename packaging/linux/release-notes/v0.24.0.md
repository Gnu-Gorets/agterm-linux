### Linux adaptations

- Add top/bottom splits, live split transposition, persisted split axes, `top`/`bottom` pane aliases,
  Close Split, and matching GTK palette and control-socket actions.
- Add keymap `|` alternatives, built-in leader sequences, deterministic Linux shortcut collision handling,
  and Linux-resolved `keymap.list` output.
- Add previous/next workspace navigation and current-workspace collapse toggling to GTK key dispatch,
  the command palette, and `workspace.go` control routing.
- Add pane-overlay copy and text read-back plus explicit surface cursor-column reporting through libghostty.
- Refuse duplicate control-socket ownership without unlinking the running instance's socket, and advertise
  an unreachable socket to shells spawned by the refused instance.
- Advance the pinned Linux libghostty build to `0ba6250`, Zig 0.16.0, and the matching deterministic theme
  archive, retaining the embedded OpenGL, input-handoff, and resource patches.
- Keep Quick Terminal in-window with an app-local shortcut.
  Linux accepts `global-hotkey` for shared configuration compatibility but does not register a
  compositor-wide shortcut.

The AppKit floating panel, global macOS hotkey registration, display-wake observer, Dock menu, TCC audio
usage string, hardened-runtime entitlements, unified logging, signing, and notarization changes remain
macOS-only.

Compatible with Ubuntu 24.04 / Debian 13 or newer and modern Fedora systems with glibc 2.39 or newer.
All artifacts are x86_64; the AppImage additionally bundles GTK4 and libadwaita.
